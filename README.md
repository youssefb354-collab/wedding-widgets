# Wedding Widgets

Embeddable widgets for Canva wedding website templates: household RSVP (→ Google Sheets), countdown, add-to-calendar and music player.

- Builder (no code): `builder.html`
- Add a widget in Canva: **Apps → Embeds → paste the link**.
